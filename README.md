## Golden Rules for AI in Embedded
1. **No Heap**: `new`, `malloc`, `std::vector` = FORBIDDEN
2. **No Exceptions/RTTI**: Compile with `-fno-exceptions -fno-rtti`
3. **Always Verify**: AI-generated code must run on real hardware
